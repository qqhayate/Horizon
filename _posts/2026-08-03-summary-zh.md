阿里巴巴开源了一款 22B 参数模型，可实现实时、分钟级稳定的数字人生成。该模型支持自定义角色与流式交互，长视频生成不再出现漂移问题。 这一突破解决了 AI 数字人领域的一大难题：长视频生成中的稳定性与一致性。阿里通过开源降低了开发者和企业构建逼真、可交互数字人的门槛，有望加速直播、教育、客服和娱乐等领域的应用落地。 该模型据称采用了可携带、可成长且能反向纠错的记忆机制，有助于保持长序列生成的一致性。值得关注的技术亮点是其实时生成能力，这在 22B 参数规模的模型中较为罕见。

## [欧盟年龄验证项目强制要求硬件绑定证明](https://linuxiac.com/eu-age-verification-project-mandates-hardware-bound-attestation/) ⭐️ 8.0/10

欧盟的年龄验证项目现在强制要求使用硬件绑定证明（hardware-bound attestation）来确认用户年龄。这一要求引发担忧：公民可能不得不依赖 Google 或 Apple 的专有设备证明服务，而桌面 Linux 用户实际上需要第二台设备才能参与。 这一决定可能为欧盟范围内的年龄检查和数字身份验证开创先例，影响在线隐私与市场竞争。批评者警告，硬件绑定证明可能将线上活动与现实身份绑定，并把 Linux 等开源平台排除在外。 相关报道指出，Linux 用户并未被明文禁止，但桌面 Linux 用户需要用受支持的移动钱包扫描二维码，实际上等于要求第二台非 Linux 设备。技术人员还指出，硬件绑定证明不使用零知识证明或盲签名，因此硬件 ID 在技术上可能暴露；此外，该应用只是临时方案，欧盟最终目标是提供具有不可关联性（unlinkability）的数字钱包。

hackernews · RobotToaster · 8月2日 20:44 · [社区讨论](https://news.ycombinator.com/item?id=49148128)

**背景**: 硬件证明（hardware attestation）是一种安全过程，用于验证设备硬件、固件和软件的完整性与真实性，通常借助可信平台模块（TPM）或类似安全元件将度量结果签名后发送给远程验证方。硬件绑定证明则将验证结果与特定的设备密钥绑定，使在线服务能够确认请求来自真实且未被篡改的设备。这种做法在技术上很强，但也让用户依赖大型平台厂商提供的证明基础设施。

## [Kakehashi：实验性用户态在 Linux ARM 上运行 macOS 二进制文件](https://github.com/wie-project/kakehashi) ⭐️ 7.0/10

Kakehashi 是一个新的实验性用户态项目，可在 Linux ARM 上原生运行 macOS 命令行二进制文件。目前已有 7-Zip、curl 以及 Xcode 自带 Git 的工作原型，并已通过多线程压缩测试和 200 多个 curl 命令测试。 这可能开辟一条无需苹果系统、在低成本 ARM Linux 硬件上运行 macOS 命令行工具的新路径，为开发者扩展兼容性选择。该项目也加入了类似于 Windows 生态中 Wine/Proton 以及既有 Darling 项目的长期兼容性探索。 该项目目前仍处于实验阶段，性能有限：7-Zip 当前比原生 Linux 慢约 5.2 倍，不过作者已制定明确的优化计划。它的实现方式是在用户态加载 Mach-O 二进制文件并翻译 macOS 系统调用，而不是使用完整虚拟机。

hackernews · vlad_kalinkin · 8月2日 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49145937)

**背景**: Mach-O 是 macOS 和 iOS 的原生可执行文件格式，而 Linux 通常使用 ELF，因此要在 Linux 上运行 macOS 二进制文件，需要处理格式加载、库桥接和系统调用翻译。用户态模拟只翻译应用程序进程，而不是整个系统，因此比全系统模拟更轻量。QEMU 的用户态模拟以及 Darling 中的 Darwin 子系统都是类似技术的例子。

## [F*：面向证明的编程语言，用于形式化验证](https://fstar-lang.org/) ⭐️ 7.0/10

F* 是一种通用的面向证明的编程语言，支持纯函数式编程和带效果的编程，使开发者能够编写程序并通过形式化证明进行验证。它集成了 SMT 求解器，并提供 Meta-F* 进行元编程。 F* 弥合了实际编程与形式化验证之间的鸿沟，对安全关键的系统和形式化方法研究具有重要价值。它已被用于 Everest 和 HACL* 等重大项目，用于验证密码学实现。 F* 使用依赖类型和带效果的类型系统来表达规范，并利用 SMT 求解器进行自动化证明检查。它支持通过允许在验证下调用外部库来逐步迁移现有 C 代码库。

hackernews · ducktective · 8月2日 12:31 · [社区讨论](https://news.ycombinator.com/item?id=49143925)

**背景**: F* 最初是一个研究项目，旨在将 OCaml 和 F# 的实用性同 Coq、Agda 等证明助理的验证能力结合起来。形式化验证利用数学证明来保证软件的正确性，对于密码协议和安全关键组件尤为重要。F* 会生成验证条件并发送给 SMT 求解器，以自动化大部分证明过程。
