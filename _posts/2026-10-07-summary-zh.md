## [OpenAI 发布预印本，声称 AI 解决多个数学公开难题](https://openai.com/index/sharing-ai-progress-in-mathematics/) ⭐️ 9.0/10

OpenAI 在 GitHub 上发布了仓库 github.com/openai/math，其中包含一批预印本，声称借助 AI 给出了大量长期悬而未决的数学公开问题的解答。根据社区对该问题清单的分析，这些预印本声称完整解决了 500 个顶级公开问题中的 90 个，包括 ℚ 上的希尔伯特第十问题、唯一游戏猜想（Unique Games Conjecture）、Baum–Connes 猜想、Landau–Siegel 零点不存在性以及 Barnette 猜想。 如果这些结果经得起检验，这将意味着自动数学发现领域可能出现范式转变——AI 系统开始攻克数十年来人类专家在复杂性理论、图论、数论和数学物理等领域未能解决的难题。这也将直接影响理论计算机科学等领域，因为唯一游戏猜想是众多不可近似性结果的底层假设，同时还可能改变数学家对公开问题的优先级排序与验证方式。 这些成果被对照社区整理的顶级公开问题清单进行编号，排名最高的包括第 22 位 ℚ 上的希尔伯特第十问题、第 29 位唯一游戏猜想、第 48 位 Landau–Siegel 零点不存在性以及第 52 位 Baum–Connes 猜想；此外还有一些相对容易理解的结果，例如三台机器单位作业调度的多项式时间算法（自 1979 年 Garey 与 Johnson 的著作以来一直悬而未决）以及 Barnette 猜想的证明。需要注意，这些只是预印本而非经过同行评审的正式论文，其证明的正确性仍需领域专家独立验证后才能确认。

hackernews · OpenAI News · 10月6日 22:17 · [社区讨论](https://news.ycombinator.com/item?id=49984923)

## [弗朗西斯·哈尔岑因冰立方中微子观测站获 2026 年诺贝尔物理学奖](https://www.nobelprize.org/prizes/physics/2026/) ⭐️ 9.0/10

2026 年 10 月 6 日，瑞典皇家科学院宣布将 2026 年诺贝尔物理学奖授予美国威斯康星大学麦迪逊分校的弗朗西斯·哈尔岑，以表彰他对冰立方中微子观测站的决定性贡献以及发现天体物理起源的高能中微子。哈尔岑早在 1988 年就提出了在南极冰层中探测中微子的构想，并作为项目首席研究员领导了整个工程。 这一奖项正式确认中微子天文学已成为成熟的观测学科，使科学家在光子和引力波之外获得了研究宇宙最高能、最不透明过程的“第二种信使”。它同时也肯定了这项持续数十年、后勤条件极其艰苦的极地科学与探测器工程投入，并有望推动多信使天文学和天体粒子物理领域的资金投入与研究热度。 冰立方由数千个球形数字光学模块（DOM）组成，每个模块串上安装 60 个，通过热水钻埋设于南极冰层下 1450 至 2450 米深处，整体覆盖约一立方公里的体积。该探测器于 2010 年 12 月 18 日建成，而其升级工程于 2026 年 2 月 12 日宣布成功部署，这是自 15 年前开工以来冰立方的首次重大扩容。

hackernews · solarist · 10月6日 09:48 · [社区讨论](https://news.ycombinator.com/item?id=49976265)

**背景**: 中微子是一种几乎无质量、不带电的基本粒子，产生于恒星内部的核反应、超新星爆发以及放射性衰变之中；它们只通过弱核力和引力与物质作用，因此数以万亿计的中微子可以毫无阻碍地穿过整个地球。在冰立方中，中微子偶尔与冰中的原子核碰撞，产生速度超过该介质中光速的带电次级粒子，发出微弱的蓝色切伦科夫辐射闪光，被光学传感器记录下来。中微子天文学正是借助这类探测器——通常建在数百米深的地下或冰层中以屏蔽宇宙射线本底——来观测光学望远镜无法捕捉的过程，而冰立方在南极的前身是南极μ子和中微子探测器阵列（AMANDA）。

## [Mistral 发布 Large 4：基于 Grace Blackwell 训练的开放权重万亿参数多模态旗舰模型](https://mistral.ai/news/mistral-large-4//) ⭐️ 8.0/10

Mistral 正式发布 Mistral Large 4，这是一款开放权重的通用多模态模型，采用细粒度 Mixture-of-Experts 架构，总参数量 1.05T、激活参数 52B，并配备 1.6B 的视觉编码器。Mistral 表示该模型是从零开始、在其位于欧洲的自有数据中心里用 3800 块 NVIDIA Grace Blackwell GPU 训练完成的。 这是 Mistral 的旗舰级发布，也是对一个关键问题的检验：一家欧洲实验室仅用约 4000 块 GPU 的集群训练，能否仍然紧咬美国和中国顶级前沿模型。对那些出于数据主权或合规考虑、希望训练与推理都发生在欧盟境内的企业来说，这一点尤为重要。早期用户还报告了价格性能上的代际跃升——某项基准测试的准确率从 58% 提升到 74%，而成本仅约为 Mistral Medium 3.5 的十分之一。 一个值得注意的技术细节是，该模型只提供 "none" 和 "high" 两档推理设置；早期测试者 Simon Willison 发现两者差别很小，"high" 模式虽然会增加一小段思考轨迹，但有时输出的 token 数反而比 "none" 更少。Mistral Large 4 还因在视觉和网络安全基准上的强劲表现受到关注，不过它并未被定位为整体最强模型。

hackernews · Philpax · 10月6日 13:15 · [社区讨论](https://news.ycombinator.com/item?id=49977979)

**背景**: Mixture-of-Experts（MoE，混合专家）是一种把模型拆分成许多专门子网络、并在每个 token 上只激活其中一小部分的架构，因此 1.05T 参数的模型可以按约 52B 激活参数的成本运行。NVIDIA 的 Grace Blackwell 是继 Hopper 之后的 GPU 世代，将 Grace CPU 与 Blackwell GPU 结合，专为超大规模生成式 AI 训练负载而设计。“开放权重”意味着训练好的参数可以下载并自行部署，与完全闭源、只能通过 API 调用的模型形成对比，这也是 Mistral 作为欧洲替代方案的核心定位。

## [Google 发布 EmbeddingGemma 2：轻量级开放多模态嵌入模型](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/) ⭐️ 8.0/10

Google DeepMind 发布了 EmbeddingGemma 2，这是一个以 Apache 2.0 许可证开放的多模态嵌入模型，可将文本（含代码）、图像、视频帧和音频映射到统一的 768 维向量空间。它采用模块化架构，参数规模从仅支持文本与代码的 270M 版本，扩展到启用全部模态时的约 740M（其中文本+视觉的配置约 440M），并将在未来数周通过 ML Kit 面向 Android 开放。 嵌入模型通常要在大规模数据上运行，其生成的向量会被长期存储，因此 Apache 2.0 的开放许可证消除了厂商下架托管模型、迫使用户重新为整个语料库生成嵌入的风险。同时，一个参数不足 10 亿的多模态模型让高质量的语义检索可以在本地笔记本和手机上运行，这对注重隐私的端侧检索场景尤为重要。 其模块化设计允许开发者只加载所需的编码器，因此纯文本部署可保持在 270M 参数，而多模态部署则可扩展到完整配置。该模型基于 Gemma 4 构建；社区提出的一个公开技术问题是，能否将其与二值量化结合使用，以替代 Matryoshka 表示学习（MRL）来压缩向量维度。

hackernews · ilreb · 10月6日 16:03 · [社区讨论](https://news.ycombinator.com/item?id=49980487)

**背景**: 嵌入模型把内容转换成数值向量，使语义相近的内容在向量空间中彼此靠近，这正是语义搜索、推荐系统和检索增强生成（RAG）的核心机制。多模态嵌入模型进一步把文本、图像、视频和音频放入同一向量空间，从而可以用文本查询检索到匹配的图像或视频片段。Gemma 是 Google DeepMind 基于与 Gemini 相同的研究和技术打造的轻量级开放模型家族，而 EmbeddingGemma 2 是该家族中专注于嵌入任务的成员。

## [OpenAI 推出 Decisions API 公测，主打快速是非判断](https://developers.openai.com/api/docs/guides/decisions) ⭐️ 7.0/10

OpenAI 发布了 Decisions API 的开发者文档，该 API 目前处于公开测试阶段，对外提供 POST /v1/decisions 端点，开发者通过 Authorization 请求头携带密钥，并在 JSON 请求体中传入模型名和输入消息即可调用。该接口的目标是快速返回结构化的“是/否”或选项式判断，而不是生成自由文本。 如果决策类调用足够便宜且足够快，意图路由、标签选择、UI 组件选择等分类任务就可以从通用对话模型迁移出去，从而给以推理调用为主要收入来源的厂商带来价格压力。这次发布也进一步点燃了业界关于“AI 推理是否已经变成受价格战支配的大宗商品市场”的讨论。 有评论者测算其成本约为每 100 万 token 0.10 美元，与直接写提示词让模型做分类基本相同，但称 Decisions 端点比 Responses API 大约快 10 倍，说明真正的差异化在于速度而非价格。由于该 API 仍处于公开测试阶段，其行为、模型名称和定价都可能继续变化，且目前公开的独立评测仍被描述为相当初步。

hackernews · chiefstorm · 10月6日 20:57 · [社区讨论](https://news.ycombinator.com/item?id=49984025)

**背景**: 所谓“决策模型”是指一种轻量组件：它只回答一个范围很窄的问题——是或否、一个标签、或者在若干选项中挑一个——一次前向计算就能给出结果，而不需要模型生成一整段文本再让调用方去解析。开发者此前已经可以通过小型开源模型（例如 Jev/SemIf 和 Mercury Decide）廉价地获得这种能力，或者直接读取现有模型的选项概率，LangChain4j 等库也提供了开箱即用的决策模型组件。Decisions API 把这一模式接入了 OpenAI 自家的第一方平台，而此时整个行业正在热议 AI 推理的商品化趋势。
